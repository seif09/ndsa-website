# NDSA · Website-Entwurf

`index.html` per Doppelklick öffnen. Die vier HTML-Dateien funktionieren ohne Installation. Die Illustration und die Links zur Schulwebsite benötigen Internetzugang.

| Inhalt | Datei |
| --- | --- |
| Startseite und Elternlinks | index.html |
| Schulprofil und Schulbereiche | ueber-uns.html |
| Aufnahme, Bewerbungsfragen und FAQ | aufnahme.html |
| Kontakt und Demoformular | kontakt.html |
| Farben und Layout | styles.css |
| Formularverhalten | kontakt.js |

Die Texte liegen direkt in den HTML-Seiten. Bei Änderungen an Navigation und Fußzeile dieselbe Anpassung auf allen vier Seiten übernehmen. Für ein späteres CMS lassen sich Kopf- und Fußzeile als gemeinsame Vorlagen und die Seiteninhalte als bearbeitbare Felder abbilden.

Vor Veröffentlichung Logo, Farben, Bildmaterial, Aufnahmeangaben, Kontaktdaten und rechtliche Seiten mit der Schule abstimmen. Das Formular öffnet eine E-Mail im lokalen E-Mail-Programm. Die Website selbst speichert und versendet keine Daten. Änderungen an der Empfängeradresse in kontakt.html beim Attribut data-recipient und in den sichtbaren Kontaktdaten vornehmen. Vor einer Veröffentlichung die Aufnahmeunterlagen und Termine für das aktuelle Schuljahr bestätigen. Bildquelle: PASCH-Initiative, Schulporträt-Platzhalter. Offizielle Inhalte: https://neue-deutsche-schule-alex.de/.
